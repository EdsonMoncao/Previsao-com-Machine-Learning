# Previsao-com-Machine-Learning
Projeto em Python sobre análise de Score de cliente em um banco.

Organização do código:
Importação da base de dados
Verificar informações vazias
Tratamento na base de dados
Selecionar as colunas de treino para o modelo
Treinamento de 2 modelos
Verificação do melhor modelo
Verificação sobre quais as características mais importantes para definir o score do cliente
